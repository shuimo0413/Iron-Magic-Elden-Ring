# P1 — 三色矿物方块（无世界生成）

**一次只做本文件。依赖 P0 已完成。做完验收后停，不要开始矿脉 / 洞穴 Feature。**

索引：[辉石世界线总计划](辉石世界线总计划_f9cb546f.plan.md)

## 目标

注册青 / 蓝 / 紫三套矿物方块与配方。颜色只改贴图与掉落，不复制三套类。

**本阶段没有世界生成。** 生存里摸不到是正常的；P2 才刷进世界。

## 必须遵守

- **Java 一份，注册三套 id。** 禁止按颜色复制三套类。
- **不生长：** 无 `Budding*`、无随机刻。四档水晶形态固定。
- **不做建材：** 无砖 / 抛光 / 灯。
- 禁止本阶段加 `configured_feature` / `placed_feature` / `biome_modifier` / 自定义 Feature。
- 水晶块 **不建模**：`cube_all` + 工具链 32×32 晶面贴图；物品模型 parent 方块。
- 四档水晶：复制原版紫水晶十字模型作占位。
- 常量进 `tuning/GlintstoneWorldTuning.java`。贴图走 `工具链/`。

## 每色一套

- `{color}_glintstone_ore` / `deepslate_{color}_glintstone_ore`：对标铁矿，挖掉掉自身，熔炼得碎片
- `small/medium/large_{color}_glintstone_bud` + `{color}_glintstone_cluster`：`AmethystClusterBlock`，簇掉碎片
- `{color}_glintstone_block`：9 碎片合成，挖掉掉自身

枚举 `GlintstoneColor`：`CYAN` / `BLUE` / `PURPLE`。新建 [ModBlocks.java](../../src/main/java/com/eldenring/spells/registry/ModBlocks.java)，在入口 **先于 ModItems** 注册。

## 不要做

- 任何 worldgen
- budding、砖、灯、星落坑、装备

## 验收

- 创造栏能拿到矿石、四档水晶、水晶块
- JEI：9 碎片→块；矿石熔炼→碎片
- 簇掉对应碎片
- `.\gradlew.bat compileJava` 通过
- [AGENTS.md](../../AGENTS.md) 勾：三色辉石矿物方块（世界生成留给 P2）
