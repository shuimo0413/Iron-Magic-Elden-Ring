# P3 — 星落坑（地表陨石坑）

**一次只做本文件。依赖 P1 紫色方块已存在。不依赖矿洞。做完即停。**

索引：[辉石世界线总计划](辉石世界线总计划_f9cb546f.plan.md)

## 目标

地表稀有陨石坑，解释「天外」。这不是晶洞，也不是辉石矿洞。地下紫色走 P2；本阶段只加地表第二种来源。

## 必须遵守

- **不新注册紫色方块。** 坑里铺 P1 的 `purple_glintstone_block` + 簇 / 芽（**不生长**）。
- 不做「不发芽的死晶体」家族。不做瑟利亚。
- **不放刷怪笼、不生成任何实体。**
- Feature 挡不住群系自然刷怪；若验收要求坑里也完全不刷，把星落坑改成带空 `spawn_overrides` 的小型 structure。
- 常量进 `GlintstoneWorldTuning`。不改法术渲染。

## 生成内容

优先 **Java/JSON Feature（程序化陨石坑）**：

- 焦黑圆坑（烧过的土 / 平滑玄武岩 / 黑石一类）
- 中心紫色水晶块 + 少量簇和芽（形态固定，不会继续长）
- 一个箱子
- 群系：平原、风蚀之地、恶地、沙漠。极稀有
- 不要和矿石、辉石矿洞、原版紫水晶抢同一噪声盐。不要做 geode。

箱子：紫色碎片、高阶墨水、帚星/毁灭流星加权。**陨石杖**若 P4 还没做，箱子里不要放不存在的物品。

## 不要做

- 新的紫色 block 类
- 矿洞 / 哨塔 / budding 生长
- 装备物品注册（那是 P4）

## 验收

- 地表能看见发光坑
- 挖到的紫色碎片能当 Focus
- 坑内不放置任何生物
- `.\gradlew.bat compileJava` 通过
- [AGENTS.md](../../AGENTS.md) 勾：地表星落坑 Feature
