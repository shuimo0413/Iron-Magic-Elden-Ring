# P4 — 粉尘、装备、合成（非法术）

**一次只做本文件。依赖 P0 碎片；粉尘掉落依赖 P1 方块；陨石杖战利品依赖 P3 星落坑箱子。做完即停。**

索引：[辉石世界线总计划](辉石世界线总计划_f9cb546f.plan.md)

## 目标

挖矿有消耗出口；法师外观；陨石杖只掉不造。

## 必须遵守

- 不做用紫水晶等原版材料合成辉石碎片的配方（粉尘可以由碎片合成，方向是碎片 → 粉尘）。
- 学徒袍不要做成铁魔法全套学派甲那么重。
- 陨石杖 **无合成表**；只出星落坑（没有矿洞箱子）。
- 不注册生物，不加新结构，不改法术渲染。
- 贴图走 `工具链/`，画布 32×32。属性数字进 Tuning。

## 物品

- `glintstone_dust`：挖晶体簇额外掉落，**或** 1 碎片合成 4 粉尘（三种颜色碎片都可）
- 学徒袍：胸甲即可，或四件套从简；配方皮革 + 粉尘
- `cyan_glintstone_staff`：木棍 + 青色辉石碎片 + 奥术精华；属性只给少量辉石强度
- `meteorite_staff`：只出星落坑。紫色头。tooltip 写清不能用常规强化

创造栏分组：碎片 / 方块 / 装备 / 卷轴。

## 不要做

- 新法术、新卷轴物品
- 学院本体、哨塔（那是 P6）
- 自定义生物

## 验收

- JEI 能看到袍子和青色辉石杖配方
- 陨石杖无配方
- 生存用粉尘能做出第一件辉石外观装备
- `.\gradlew.bat compileJava` 通过
